# 项目简介（用于 Issue 申请 / 对外一页纸介绍）

## 一句话

「麦麦成长时刻（Time to McDonald）」把「去麦当劳的路上」和「等麦当劳的那 7 分钟」这两段被浪费的碎片时间，变成可累积的成长记录：路上记里程与热量消耗，等餐背单词，点餐前按你的身体数据算好这一餐该怎么吃。

## 它解决什么问题

一个人从「想吃麦当劳」到「吃到麦当劳」，中间有两段最无聊的空白：路上的 5–15 分钟和等餐的 5–15 分钟。市面上的工具都在优化「点单」这个动作本身，没有人管这两段空白。本项目基于麦当劳官方 MCP（门店查询、营养库、订单状态、服务端时间）与腾讯位置服务（步行/骑行路径规划），把整个旅程变成一条有记录的成长链路。

## 核心能力

1. **出发**：地址输入或一键定位，找到最近门店并给出真实步行/骑行耗时与消耗的卡路里；没有地图 API 时按距离估算并明确标注。
2. **吃什么**：按 BMI / 活动量 / 目标（Mifflin-St Jeor 公式）算出本餐热量与蛋白/脂肪/碳水目标，从麦当劳真实营养库中枚举并打分推荐组合。
3. **下单**：每家门店一个「It's Time to Mc」按钮，跳转麦当劳官方渠道完成下单——本项目不调下单接口、不碰支付、不存储账号。
4. **等餐**：每 5 秒轮询订单状态（MCP 4.2.13），剩余时间自动折算成可背的单词量；CET-4 词库 + SM-2 间隔重复，错词自动回流。
5. **自动记账**：下单后每 2 分钟盯单，出现新订单即自动把通勤消耗、订单营养、等餐专注时长一次性写入本地成长档案。
6. **成长看板**：像素风界面、达标餐/单词/消耗/蛋白四张数据卡、成就徽章、连续打卡；吉祥物小汉堡随 8 个等级称号逐步换装（冒芽 → 方巾 → 薯条骑士 → 厨师帽 → 皇冠）。

## 技术特点

- 纯 Python 标准库实现（零第三方依赖），`python run.py web` 一条命令启动；
- 136 项单元测试全绿；真实 MCP 联调中修复 10+ 个 mock 掩盖不了的结构问题；
- 隐私优先：Token 只在服务端，定位坐标不上传不入库，健康档案只存本地 SQLite；
- 合规优先：演示模式连订单都用假数据，所有降级（无地图 Key / 无 Token）都在界面如实标注，绝不把估算值伪装成真实数据。

## 形态与平台

本地 Web 应用（桌面 / 手机浏览器均可，响应式适配）+ CLI 工具集，可在 WorkBuddy 等 AI 助手中对话式驱动，也可完全独立运行，不绑定任何特定平台。

## 一句话总结

**别人帮你更快点到餐，我们帮你把等餐的时间变值钱。麦门！**
